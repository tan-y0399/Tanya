## 4 关键业务流程

### 4.1 用户请求到执行闭环（序列说明）

1. 用户输入自然语言  
2. 会话上下文组装  
3. 感知层拉取/刷新状态快照（可选、按策略触发）  
4. LLM 规划/选工具  
5. 护栏：静态拦截 → 动态意图对齐 →（高风险）人工审批  
6. 最小权限执行器调用 MCP Tool  
7. 结果回写、审计日志、前端展示  

（建议附序列图。）

### 4.2 ReAct / Plan-Execute 路由策略

- 任务分类规则（关键词、步骤数估计、风险等级等）。
- 混合模式：全局 Plan + 子步 ReAct 的衔接方式。

### 4.3 根因分析流程（若实现）

- 告警触发 → 多源关联 → RAG → 方案 → 安全校验 → 执行/仅建议。
