# 数据库设计文档

> **项目名称**：面向麒麟操作系统的安全智能运维 Agent 设计与实现
> **版本**：V1.0&emsp;**日期**：2026-05-18&emsp;**编写**：项目组

---

## 1 概述

### 1.1 设计目标

- 存储用户、会话、消息等业务数据
- 独立存储审计日志，仅追加不修改
- 支持审批流转记录
- 开发阶段使用 SQLite，生产环境可切换 MySQL

### 1.2 数据库选型

| 环境 | 数据库 | 说明 |
|------|--------|------|
| 开发 | SQLite 3 | 单文件、零配置 |
| 生产 | MySQL 8.0+ | 主备支持、并发性能 |

### 1.3 命名规范

| 对象 | 规范 | 示例 |
|------|------|------|
| 表名 | 小写蛇形命名、名词复数 | `users`、`audit_records` |
| 主键 | `id` | `users.id` |
| 外键 | `{表名单数}_id` | `user_id` |
| 时间戳列 | `created_at`、`updated_at` | — |
| 索引 | `idx_{表}_{列}` | `idx_sessions_user_id` |
| 唯一索引 | `uk_{表}_{列}` | `uk_users_username` |

## 3 表结构详细设计

### 3.1 users — 用户表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| username | VARCHAR(64) | UK, NOT NULL | 用户名 |
| password_hash | VARCHAR(256) | NOT NULL | bcrypt 哈希 |
| role | VARCHAR(32) | NOT NULL, DEFAULT 'admin' | 角色：admin / auditor / deployer |
| is_active | BOOLEAN | NOT NULL, DEFAULT TRUE | 是否启用 |
| created_at | DATETIME | NOT NULL, DEFAULT NOW() | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT NOW() | 更新时间 |

**索引**：

| 索引名 | 列 | 类型 |
|--------|-----|------|
| `uk_users_username` | username | UNIQUE |
| `idx_users_role` | role | BTREE |

**建表 SQL**：

```sql
CREATE TABLE users (
    id VARCHAR(36) PRIMARY KEY,
    username VARCHAR(64) NOT NULL UNIQUE,
    password_hash VARCHAR(256) NOT NULL,
    role VARCHAR(32) NOT NULL DEFAULT 'admin',
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 sessions — 会话表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| user_id | VARCHAR(36) | FK→users.id, NOT NULL | 所属用户 |
| title | VARCHAR(256) | NOT NULL, DEFAULT '新会话' | 会话标题 |
| status | VARCHAR(32) | NOT NULL, DEFAULT 'active' | active / archived / deleted |
| message_count | INTEGER | NOT NULL, DEFAULT 0 | 消息数量（冗余计数） |
| created_at | DATETIME | NOT NULL, DEFAULT NOW() | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT NOW() | 最后更新时间 |

**索引**：

| 索引名 | 列 | 类型 |
|--------|-----|------|
| `idx_sessions_user_id` | user_id | BTREE |
| `idx_sessions_updated_at` | updated_at | BTREE |

**建表 SQL**：

```sql
CREATE TABLE sessions (
    id VARCHAR(36) PRIMARY KEY,
    user_id VARCHAR(36) NOT NULL REFERENCES users(id),
    title VARCHAR(256) NOT NULL DEFAULT '新会话',
    status VARCHAR(32) NOT NULL DEFAULT 'active',
    message_count INTEGER NOT NULL DEFAULT 0,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### 3.3 messages — 消息表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| session_id | VARCHAR(36) | FK→sessions.id, NOT NULL | 所属会话 |
| role | VARCHAR(32) | NOT NULL | user / assistant / tool_call / system |
| content | TEXT | NOT NULL | 消息内容 |
| tool_calls | JSON | NULL | 工具调用信息（role=assistant 时） |
| trace_id | VARCHAR(64) | NULL | 关联 TraceId |
| metadata | JSON | NULL | 额外元数据（token 用量等） |
| created_at | DATETIME | NOT NULL, DEFAULT NOW() | 创建时间 |

**索引**：

| 索引名 | 列 | 类型 |
|--------|-----|------|
| `idx_messages_session_id` | session_id | BTREE |
| `idx_messages_trace_id` | trace_id | BTREE |
| `idx_messages_created_at` | created_at | BTREE |

**建表 SQL**：

```sql
CREATE TABLE messages (
    id VARCHAR(36) PRIMARY KEY,
    session_id VARCHAR(36) NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
    role VARCHAR(32) NOT NULL,
    content TEXT NOT NULL,
    tool_calls JSON,
    trace_id VARCHAR(64),
    metadata JSON,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### 3.4 audit_records — 审计日志表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| trace_id | VARCHAR(64) | NOT NULL | 全链路 TraceId |
| session_id | VARCHAR(36) | NULL | 关联会话 |
| user_id | VARCHAR(36) | NULL | 操作用户 |
| event_type | VARCHAR(64) | NOT NULL | 事件类型 |
| sequence | INTEGER | NOT NULL | 同 traceId 内序号 |
| event_data | JSON | NOT NULL | 事件详细数据 |
| created_at | DATETIME | NOT NULL, DEFAULT NOW() | 创建时间 |

**event_type 枚举值**：

| 值 | 说明 |
|----|------|
| USER_MESSAGE | 用户消息接收 |
| PERCEPTION | 系统感知采集 |
| LLM_CALL | 大模型调用 |
| SECURITY_CHECK | 安全校验 |
| APPROVAL | 审批流转 |
| TOOL_EXECUTION | 工具执行 |
| AGENT_RESPONSE | Agent 回复 |

**索引**：

| 索引名 | 列 | 类型 |
|--------|-----|------|
| `idx_audit_trace_id` | trace_id | BTREE |
| `idx_audit_user_id` | user_id | BTREE |
| `idx_audit_event_type` | event_type | BTREE |
| `idx_audit_created_at` | created_at | BTREE |

**建表 SQL**：

```sql
CREATE TABLE audit_records (
    id VARCHAR(36) PRIMARY KEY,
    trace_id VARCHAR(64) NOT NULL,
    session_id VARCHAR(36),
    user_id VARCHAR(36),
    event_type VARCHAR(64) NOT NULL,
    sequence INTEGER NOT NULL,
    event_data JSON NOT NULL,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- 仅追加权限（应用层保证）：不授予 UPDATE/DELETE 权限
```

### 3.5 approvals — 审批表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| trace_id | VARCHAR(64) | NOT NULL | 关联 TraceId |
| session_id | VARCHAR(36) | NULL | 关联会话 |
| requested_by | VARCHAR(36) | NOT NULL | 发起审批的用户 ID |
| tool_name | VARCHAR(128) | NOT NULL | 工具名称 |
| tool_params | JSON | NOT NULL | 工具参数 |
| risk_level | VARCHAR(8) | NOT NULL | 风险等级：L1/L2/L3/L4 |
| detail | TEXT | NULL | 审批内容描述 |
| status | VARCHAR(32) | NOT NULL, DEFAULT 'pending' | pending / approved / rejected / timeout |
| approver_id | VARCHAR(36) | NULL | 审批人 ID |
| comment | TEXT | NULL | 审批意见 |
| created_at | DATETIME | NOT NULL, DEFAULT NOW() | 发起时间 |
| expires_at | DATETIME | NOT NULL | 超时时间 |
| resolved_at | DATETIME | NULL | 审批完成时间 |

**索引**：

| 索引名 | 列 | 类型 |
|--------|-----|------|
| `idx_approvals_status` | status | BTREE |
| `idx_approvals_trace_id` | trace_id | BTREE |
| `idx_approvals_requested_by` | requested_by | BTREE |

**建表 SQL**：

```sql
CREATE TABLE approvals (
    id VARCHAR(36) PRIMARY KEY,
    trace_id VARCHAR(64) NOT NULL,
    session_id VARCHAR(36),
    requested_by VARCHAR(36) NOT NULL REFERENCES users(id),
    tool_name VARCHAR(128) NOT NULL,
    tool_params JSON NOT NULL,
    risk_level VARCHAR(8) NOT NULL,
    detail TEXT,
    status VARCHAR(32) NOT NULL DEFAULT 'pending',
    approver_id VARCHAR(36) REFERENCES users(id),
    comment TEXT,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    expires_at DATETIME NOT NULL,
    resolved_at DATETIME
);
```

### 3.6 system_configs — 系统配置表

| 列名 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | VARCHAR(36) | PK | UUID |
| config_key | VARCHAR(128) | UK, NOT NULL | 配置键 |
| config_value | TEXT | NOT NULL | 配置值（JSON） |
| description | VARCHAR(256) | NULL | 配置说明 |
| updated_by | VARCHAR(36) | NULL | 更新人 |
| updated_at | DATETIME | NOT NULL, DEFAULT NOW() | 更新时间 |

**预设配置项**：

| config_key | 说明 | 默认值 |
|------------|------|--------|
| `llm.model` | 模型名称 | `qwen-plus` |
| `llm.api_base` | 模型 API 地址 | `https://api.example.com/v1` |
| `llm.temperature` | 模型温度参数 | `0.1` |
| `llm.max_tokens` | 最大输出 Token | `4096` |
| `tool.default_timeout` | 工具默认超时（秒） | `60` |
| `tool.enabled_tools` | 启用的工具列表 | `["get_cpu_info","get_memory_info",...]` |
| `security.approval_timeout` | 审批超时（秒） | `60` |
| `security.max_rounds` | 最大对话轮数 | `20` |
| `perception.cache_ttl` | 感知数据缓存 TTL（秒） | `10` |

**建表 SQL**：

```sql
CREATE TABLE system_configs (
    id VARCHAR(36) PRIMARY KEY,
    config_key VARCHAR(128) NOT NULL UNIQUE,
    config_value TEXT NOT NULL,
    description VARCHAR(256),
    updated_by VARCHAR(36) REFERENCES users(id),
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

## 4 SQLite 与 MySQL 差异说明

| 差异点 | SQLite | MySQL | 兼容方案 |
|--------|--------|-------|----------|
| 主键自增 | AUTOINCREMENT | AUTO_INCREMENT | 使用 UUID 字符串（无需自增） |
| 日期类型 | TEXT/DATETIME | DATETIME | ISO 8601 字符串，统一 DATETIME 类型 |
| JSON 类型 | TEXT(JSON) | JSON | SQLAlchemy JSON 类型自动适配 |
| 外键约束 | 默认关闭，需 PRAGMA | 默认开启 | SQLAlchemy 自动处理 |
| 大小写 | 默认不区分 | 区分 | 所有比较使用统一大小写 |
| 并发写入 | 单写锁 | 行级锁 | 开发阶段 SQLite 足够 |

## 5 数据库迁移

使用 Alembic 管理数据库版本迁移：

```
backend/
├── alembic/
│   ├── versions/
│   │   ├── 001_init.py        # 初始建表
│   │   └── 002_add_xxx.py     # 后续变更
│   └── env.py
└── alembic.ini
```

**初始化迁移命令**：

```bash
cd backend
alembic init alembic
alembic revision --autogenerate -m "init"
alembic upgrade head
```

## 6 数据安全

### 6.1 敏感数据处理

| 数据 | 保护方式 |
|------|----------|
| 用户密码 | bcrypt 哈希存储，不存明文 |
| JWT Secret | 环境变量注入，不落库 |
| LLM API Key | 环境变量注入，不落库 |
| 审计日志 | 仅追加，应用层禁止 UPDATE/DELETE |
| 用户输入中的敏感信息 | 日志脱敏（如检测到密码/Token 模式自动打码） |

### 6.2 备份策略

- SQLite：定期复制 `.db` 文件
- MySQL：mysqldump 定时备份 + binlog
- 审计日志：独立备份，保留 6 个月
